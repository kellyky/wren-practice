# About

Practicing the Wren language - using Exercism's [Wren track](https://exercism.org/tracks/wren).

## How to use this Repository

- `<exercise>/src/`
  - My code and approach to the exercise
- `<exercise>/test/`
  - Exercism's tests (provided here for context only)
- `<exercise>/<EXERCISE>.md`
  - Briefly describes the exercise
  - Links to it in Exercism

